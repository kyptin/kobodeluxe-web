# Kobo Deluxe for the web

This is an unofficial WebAssembly port of [Kobo Deluxe](https://github.com/olofson/kobodeluxe)
by David Olofson, based on XKobo by Akira Higuchi. It is GPL-2, like the original.

Play it at [jeffterrell.tech/kobo](https://jeffterrell.tech/kobo/), and read the
[post about it](https://jeffterrell.tech/posts/2026-10-26-kobo-deluxe-in-the-browser/).

The game code is unchanged. Everything specific to the browser lives in
`emscripten/`:

- The game is written for SDL 1.2. It runs on [sdl12-compat](https://github.com/libsdl-org/sdl12-compat),
  which implements SDL 1.2 on top of SDL2, and SDL2 provides the browser support.
  Both libraries are linked statically. SDL2's public symbols are renamed to
  `SDL2R_*` (`sdl2_rename.h`, generated by the build), and `sdl2_symtab.c` stands
  in for `dlopen()`/`dlsym()`. Small patches to SDL2 and sdl12-compat are in `*.patch`.
- `img_shim.c` replaces SDL_image with a minimal `IMG_Load()` based on stb_image.
- `shell.html` and `pre.js` provide the web page, a click-to-start overlay
  (browsers only allow audio after a click), and scores and settings saved in
  IndexedDB.

## Building

Install [emsdk](https://emscripten.org/docs/getting_started/downloads.html), then:

    source /path/to/emsdk/emsdk_env.sh
    ./emscripten/build.sh              # output in build-web/out/
    KOBO_EMBED=1 ./emscripten/build.sh # game data inside the .wasm (no .data file)

Serve `build-web/out/` from any static web server.
